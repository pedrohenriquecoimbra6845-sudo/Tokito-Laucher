# Task MODS-INGAME — enable/disable mods, download mods/textures/shaders inside the game, fast restart
Worktree: its own (e.g. /home/claude/wt/mods). String/setting prefix: `mods_` / `TokitoModsSettings`. Read COMMON.md first.

User (pt-BR, 2026-11-24): "faça uma Opção que você possa Desativar mods e ativar e além disso baixar os mods e texturas e Shaders dentro do jogo e quando tire um mod o Minecraft reinicia mais rápido para que a pessoa não espere 35 segundos, mas se acaso o Mod for pesado ele demorará".

1. Mod manager (launcher side first): list the mods of the selected version (find how Zalith resolves the version's game dir / mods dir), each with icon + name + version (read fabric.mod.json / quilt.mod.json / META-INF/mods.toml / mcmod.info), size, a toggle that enables/disables by renaming `<file>.jar` <-> `<file>.jar.disabled` (atomic rename; Fabric/Quilt/Forge/NeoForge all ignore `.disabled`), delete, enable-all / disable-all, search filter, a "changes pending: restart to apply" banner; handle name collisions; never touch files outside the mods dir.
2. Inside the game: Mods / Textures / Shaders tabs in the bottom sheet opened by the flower ball (TokitoGameSheet.kt; the chat task edits that file too: add your tabs through a small hook list, minimal edits): the mod manager above + search & install of mods, resource packs and shader packs from Modrinth/CurseForge using the existing downloader code (game/download/addon/**, platform search) running in the GAME process (network + file IO work there); install into the version's mods / resourcepacks / shaderpacks dirs; show progress; say clearly when a restart is needed (mods) and when not (resource packs and shaders can usually be applied in-game).
3. Fast restart ("Aplicar e reiniciar"): after enabling/disabling/removing/adding a mod, one button restarts Minecraft quickly: stop the game cleanly and relaunch the same version directly (skip the launcher's pre-launch checks and the assets/libraries re-verification because only mods changed, keep the Tokito loading overlay with a "quick restart" label and REAL progress from the game log; no fake bar). Time depends on the mods: a light change should be much faster than the first launch, heavy mods take longer (that is accepted by the user; never promise a fixed time, 35 s was only the first-launch goal). Possible speed-ups: reuse the warm disk cache, same JVM args, no re-extraction of natives/runtime when unchanged, optional AppCDS class-data-sharing archive (-XX:SharedArchiveFile / -XX:ArchiveClassesAtExit) ONLY if the bundled runtimes support it (check the runtime version first; never enable when unsure).
Files: new ui/components/mods/**, tokito/mods/**, a hook in TokitoGameSheet.kt, the quick-restart path in game/launch/**, part_mods.py.
